# FAQ commerciale (réponses pour l'équipe et les partenaires)

*English: [../en/15-sales-faq.md](../en/15-sales-faq.md)*

Réponses validées pour la version 2.0.0. Si une question n'est pas ici, ne pas improviser :
« Je vérifie et je vous réponds d'ici [délai]. »

| Question | Réponse |
|---|---|
| Combien ça coûte ? | Pendant le programme pilote : gratuit, sans moyen de paiement. Les prix seront fixés à partir des résultats du pilote et publiés, en CDF et en USD, avant toute facturation. |
| Est-ce conforme à la DGI ? | Nhill est un logiciel de gestion. Il n'est **pas homologué** pour la facture normalisée. Si vous êtes assujetti à la TVA, gardez votre dispositif DGI pour vos factures fiscales ; Nhill vous permet d'y noter la référence pour le rapprochement. |
| Ça marche sans internet ? | Non : Nhill a besoin d'une connexion pour enregistrer. Une opération coupée par une panne se relance sans être comptée deux fois. Pour une longue coupure, un carnet de secours puis une saisie après. |
| Sur quels appareils ? | Nhill Business : Windows 10/11 64 bits, Linux (Debian 13, Ubuntu 24.04), Android 7 et plus. Nhill POS : Windows et Linux. *(Vérifier les livrables disponibles avant de répondre.)* |
| Faut-il une imprimante spéciale ? | Non. Le ticket est un PDF de 58 ou 80 mm imprimable sur une imprimante de tickets ou une imprimante classique. |
| Mes données sont-elles en sécurité ? | Chaque établissement est isolé des autres dans la base ; échanges chiffrés ; mots de passe jamais stockés en clair ; journal d'audit. Aucun logiciel n'est sans faille : nous n'avons pas encore fait d'audit externe, c'est prévu. |
| Qui voit mes données ? | Vous et les personnes que vous invitez. L'équipe Nhill ne voit pas vos factures ni vos clients ; seulement des chiffres globaux d'utilisation, et chaque consultation est inscrite dans votre journal. |
| Où sont hébergées les données ? | [À compléter quand l'hébergeur et la région seront choisis — voir `docs/fr/parametres-legaux.md`.] |
| Puis-je récupérer mes données ? | Oui, à tout moment : exports CSV et PDF. À la fin du pilote ou de l'abonnement, vous gardez l'export. |
| Combien d'utilisateurs ? | Autant de comptes que l'offre le permet ; pendant le pilote, [N]. Chaque personne a son propre compte. |
| J'ai oublié mon mot de passe. | La version 2.0 ne permet pas encore de le réinitialiser : gardez-le dans un gestionnaire de mots de passe. C'est prévu dans une prochaine version. |
| Le mot de passe doit-il être compliqué ? | Au moins 8 caractères, pas un mot de passe trop courant. Une courte phrase se retient facilement. Pas d'obligation de le changer régulièrement. |
| Gérez-vous plusieurs magasins ? | Plusieurs caisses et, selon l'offre, plusieurs dépôts avec transferts de stock. |
| Et la comptabilité ? | Nhill produit journaux des ventes, paiements, dépenses, créances et dettes, exportables pour votre comptable. Ce n'est pas un logiciel de comptabilité générale. |
| Le paiement Mobile Money est-il intégré ? | Vous enregistrez un paiement Mobile Money (montant, référence) ; Nhill ne pilote pas les opérateurs. |
| Qui vous êtes ? | [Présentation de l'équipe et de la société exploitante, avec RCCM — à compléter.] |
| Puis-je devenir partenaire ? | Oui : recommandation, installation, formation, accompagnement. Conditions par contrat écrit. Page « Partenaires » du site. |
