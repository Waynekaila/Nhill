## 1. Current situation

The website nhill.online **sets no cookie** and uses **no tracker**: no analytics, no
advertising, no embedded social-network button, no font or script loaded from a third-party
service. Fonts and scripts are served by the website itself.

The only technical data is what any web server receives (IP address, page requested,
browser type) to deliver the page; the server log [is kept [N] days / is not kept] **[TO
COMPLETE according to the host's configuration]**. The forms use a non-reversible
fingerprint of the IP address to limit abuse (privacy policy, template 03).

The Nhill applications do not use cookies: the session is stored in the device's secure
keychain.

## 2. If a tool is added later

Before adding an analytics tool or third-party content:

1. update this document and the record of processing (template 18);
2. ask for **prior consent** for any non-essential tracker, through a banner offering
   "Accept" and "Refuse" with the same prominence;
3. allow consent to be withdrawn at any time (footer link);
4. set no non-essential tracker before the choice is made.
