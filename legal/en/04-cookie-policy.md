## 1. Current situation

The nhill.online website **sets no cookie** and uses **no tracker**: no audience
measurement, no advertising, no embedded social network button, no browser storage, no
font or script loaded from another site. Fonts and scripts are served by the website
itself.

The server that delivers the pages receives, like any web server, the technical data
needed to deliver them (IP address, page requested, browser type). The forms calculate a
non-reversible fingerprint of the IP address to limit repeated submissions; it is erased
after 30 days (privacy policy, document 03).

The Nhill applications use no cookies: the session is kept in the device's secure
keychain.

## 2. If a tool is added later

Before adding a measurement tool or content from another site:

1. update this document, the privacy policy and the record of processing (document 18);
2. ask for **prior consent** for any non-essential tracker, through a banner offering
   "Accept" and "Refuse" with equal visibility;
3. allow consent to be withdrawn at any time (footer link);
4. set no non-essential tracker before the person has chosen.
