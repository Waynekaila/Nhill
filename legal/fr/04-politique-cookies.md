## 1. Situation actuelle

Le site [ADRESSE DU SITE] **ne dépose aucun cookie** et n'utilise **aucun traceur** :
pas de mesure d'audience, pas de publicité, pas de bouton de réseau social intégré, pas de
police ni de script chargé depuis un service tiers. Les polices et scripts sont servis par
le site lui-même.

Seules données techniques : celles que tout serveur web reçoit (adresse IP, page demandée,
type de navigateur) pour acheminer la page ; le journal du serveur [est conservé [N] jours /
n'est pas conservé] **[À COMPLÉTER selon la configuration de l'hébergeur]**. Les formulaires
utilisent une empreinte non réversible de l'adresse IP pour limiter les abus (politique de
confidentialité, modèle 03).

Les applications Nhill n'utilisent pas de cookies : la session est conservée dans le
trousseau sécurisé de l'appareil.

## 2. Si un outil est ajouté plus tard

Avant d'ajouter un outil de mesure ou un contenu tiers :

1. mettre à jour ce document et le registre des traitements (modèle 18) ;
2. demander le **consentement préalable** pour tout traceur non indispensable, par un
   bandeau offrant « Accepter » et « Refuser » avec la même visibilité ;
3. permettre de retirer le consentement à tout moment (lien en pied de page) ;
4. ne déposer aucun traceur non indispensable avant le choix.
